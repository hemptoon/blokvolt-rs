# L-BG — заметки по болгарской локализации мирового слоя

Пул 3, 09.11.2026. Язык впрок, в прод не включён (включение — после ворот G8).

## Форма обращения и тон
- Безлично или вежливое «Вие» (повелительное мн. ч.: «Опитайте», «Изберете», «Проверете»). Без «ние/наш», без «редакция».
- Кнопки и пункты меню — отглагольное существительное («Изпращане», «Затваряне», «Изтегляне на данните»), как принято в болгарских интерфейсах.
- Без «24/7», без «веднага» как обещания, без оценок сетей. Evolako не упоминается.

## Плюралы
- CLDR bg: `one`, `other` (Babel 2.18). Только ключи `pl_*`.
- Мужской род после числа — бройна форма: `pl_city` → `{"one": "град", "other": "града"}` («12 града», не «градове»).
- `_in`-варианты совпадают с обычными: в болгарском нет падежей, «в 12 града».

## Единицы и числа
- Единицы кириллицей по БДС: кВт, кВт·ч, км, /мин. Технические классы AC / DC / HPC — латиницей, как в EN.
- `pct` = `{x} %` (пробел перед %, как в sr/ru). Десятичный разделитель — запятая, тысячи — пробел (для K8-реестра: `dec=','`, `thou=' '`).

## Термины (glossary.csv не содержит bg — выбраны так)
- charging station / charger → «зарядна станция» (в списках и заголовках), «зарядно (устройство) у дома» для домашнего.
- charging location / place → «място за зареждане» / «място».
- charging point → «точка за зареждане».
- public → «обществен» (единообразно во всех файлах; «публичен» заменён).
- ad hoc → «без договор» (`plan_adhoc` «Без договор», в карточке «Цена без договор»).
- plan → «план»; subscription → «абонамент».
- household electricity → «битова електроенергия» (термин КЕВР).
- VAT → ДДС; ECB → ЕЦБ.
- reliability → «надеждност на данните».
- report an error → «Сигнал за грешка» (кнопка в карточке точки и ссылки на неё в текстах).
- card (карточка точки на карте) → «карточка», чтобы не путать с «карта» (map).
- breadcrumbs → «Навигационна пътечка».

## Названия
- Страны — `name_bg` из `names/countries.csv`, сверено с Babel. Слаги — Streamlined System (закон 2009), ASCII.
- Предлог: «в», перед в/ф — «във» («във Франция»). Острова — «на» («на Фарьорските острови»), check.py это допускает.
- Города: Болгария и `stage=month` — вручную/с проверкой (`decl_ok=1`); остальные — автоконверсия из RU по правилам (ы→и, э→е, нем./нидерл. h → х и т. д.), `decl_ok=0`, `note=авто из RU`. Падежей нет, так что `in_phrase` грамматичен и при `decl_ok=0`; 0 значит «название не вычитано глазами».

## Слаги разделов
`/bg/`, `/bg/karta/`, `/bg/zaryadni-stantsii/`, сеть `mrezha`, `za-dannite`, `izteglyane`, `/bg/zaryadni-mrezhi/`, `/bg/tseni-za-zaryazhdane/`, `/bg/za-blokvolt/` (не `za-nas` — «о нас» нарушает безличность), `/bg/iztochnitsi/`, `/bg/metodologiya/`.

Независимый агент вслепую перевёл 60 случайных строк (seed 20261109) обратно в EN и сверил с оригиналом: ok 54, minor 6, mismatch 0. Запрещённых слов нет, бройная форма и в/във — верно.
