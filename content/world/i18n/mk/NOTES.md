# L-MK — македонски (mk), мировой слой — заметки

## Форма обращения и тон
- Безлично; где нужна форма — вежливое «Вие» (`Пријавете грешка`, `Проверете`, `Обидете се`), как в разделе `/mk/` (`content/com/local/mk/strings.json`).
- Короткие кнопки — краткий императив, как в glossary и `/mk/`: `Преземи податоци`, `Прикажи`, `Сподели`, `Отвори ја мапата`. Обратный перевод отметил разнобой «Отвори» / «Отворете» — оставлено намеренно (кнопка = короткая форма, текст = вежливая).
- Без «ние/наш», «редакција», «24/7», Evolako. Проверяет `check.py`.

## Термины (glossary `mk` + раздел /mk/)
- charging station / charger → **полнач**; location → **локација**; charging point → **место за полнење**; power → **моќност**; connector → **приклучок**; data reliability → **доверливост на податоците**; network → **мрежа**.
- ad hoc → **без договор** (в /mk/ колонка называется «Без регистрација»; для индекса цен «без договор» точнее передаёт «без договора/подписки»). Спорно — свести с /mk/ при включении.
- plan → **пакет**; VAT → **ДДВ**; ECB → **ЕЦБ**; household electricity → **струја за домаќинства**.
- Названия источников, лицензий и цитата индекса («BlokVolt, European EV Charging Price Index…») не переводятся.

## Плюралы
- CLDR mk (Babel): `one`, `other` (one = 1, 21, 31…, кроме 11).
- Для мужского рода после числа — счётная форма: `5 града` (литературная норма). Остальные: `земја/земји`, `мрежа/мрежи`, `локација/локации`, `место/места за полнење`.
- `_in`-варианты совпадают с обычными: в македонском нет падежей («во 5 града»).

## {country_u}, in_phrase
- В македонском нет падежей: `in_phrase` = «во X», `decl_ok = 1` для всех городов.
- «на» для 26 островных стран/территорий (Кипар, Малта, Исланд, Куба, Јамајка…) — отмечено в `note`; Исланд/Куба/Доминиканска Република — спорно, нужен носитель.

## Адреса — ВОПРОС АНДРЕЮ
`/mk/` на blokvolt.com уже занят местным разделом Северной Македонии (`/mk/`, `/mk/mapa/`, `/mk/ceni/`, `/mk/metodologija/` …). Пример контракта (`home: /<код>/`, `map: /<код>/karta/`) здесь даёт коллизию. Допущение: мировой слой живёт в той же папке `/mk/`, но на непересекающихся адресах:
`home /mk/svet/`, `map /mk/svetska-mapa/`, `hub /mk/polnachi/`, `gnet /mk/mrezhi-za-polnenje/`, `prices /mk/ceni-na-polnenje/`, `shell_about /mk/za-blokvolt/` (не «za-nas» — безличность), `sources /mk/izvori/`, `methodology /mk/metodologija-na-podatocite/`. Транслит — официальная македонская латиница (ч→ch, ж→zh, ш→sh, ѓ→gj, ќ→kj).
`check.py` проверяет, что ни один путь не совпадает со слагами `/mk/`. Та же проблема будет у L-HR (`/hr/`). K8 должен решить: общий `/mk/` (местный хаб = главная мира на mk) или отдельный префикс.
