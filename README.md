# blokvolt-rs

Static site generator for **www.blokvolt.rs** — a neutral guide to electric cars in Serbia:
a register of firms that sell and install home chargers (same public columns for every firm,
including the operator's own offer marked as "naša ponuda"), price comparison, guides
for apartment buildings (skupština, metering, who pays for electricity), public charging
(networks, per-minute prices, free chargers) and data pages (subsidies, EV statistics,
tolls/parking, registration and taxes, import and customs, insurance, loans, service).

Hosting: Cloudflare Pages, project `blokvolt` (direct upload, no build step). Cost: €0.

## Layout

- `build.py` — the whole generator (Jinja2 + Markdown + BeautifulSoup). Run `python3 build.py`, output goes to `dist/`.
- `templates/` — page templates: `base.html`, `_nav.html`, `_footer.html`, `home.html`, `firma.html`, `firme_index.html`, `grad.html`, `article.html`, `podaci_index.html`, `operator.html`, `javno_index.html`, `_cena_tabela.html` (the comparison table regenerated from firm records).
- `content/firme/*.json` — one record per firm (group A–E, cells, verdicts, sources, `verified` date, `publish` flag). Leads under review carry `"group": "L", "publish": false` — they are unverified and not published on the site.
- `content/podaci/*.md` — data/policy pages (front matter: `title`, `description`, `path`, `updated`, `next_check`, `sources` as `Label :: URL | Label :: URL`).
- `content/vodici/*.html` — the legacy guide pages (mirrored from the previous Webflow-era site, byte-exact); `build.py::patch_legacy()` swaps their nav/footer and regenerates the table block on the price page.
- `content/operateri/*.json` — public charging networks and payment apps (generated by `scripts/add_operators.py`), rendered at `/javno-punjenje/<slug>/`.
- `content/javno/` — `indeks-cena.json` (the public-charging price index: every row has a source, a date and a confidence note) and pages under `/javno-punjenje/`.
- `static/assets/` — `site.css`/`site.js` (design system v3 + article system v2), `agg.css` (aggregator additions), icons, OG image. Fonts are **not** committed — see below.
- `scripts/` — `parse_existing.py` (imports the original 20 firms from the price page), `add_new_firms.py` (the 22 firms added 22.09.2026 + 16 leads), `add_operators.py` (public charging operators), `fetch_fonts.sh`, `shots.py` (Playwright screenshots against a local server).

## Build & deploy

```bash
pip install jinja2 markdown beautifulsoup4
bash scripts/fetch_fonts.sh          # once: copies Onest woff2 from @fontsource-variable/onest into static/assets/fonts/
python3 build.py                     # -> dist/ (≈80 URLs, sitemap.xml, robots.txt, _redirects, _headers, 404.html)
cd dist && zip -r ../blokvolt-dist.zip .
```

Deploy: Cloudflare dashboard → Workers & Pages → `blokvolt` → **Create deployment** → upload the zip → Save and deploy.
`_redirects` sends the old product URLs (`/paketi-i-cene`, `/proveri-svoju-garazu`, …) to www.evolako.rs with 301 and
forces `blokvolt.rs` → `www.blokvolt.rs`.

Local preview: `python3 -m http.server 8787 --directory dist` (note: the local server needs `.html` in URLs; Pages does not).

## Editorial rules (short)

Only public, verifiable data with a source URL and a check date. Same fields for every firm; the operator's own offer
is listed in the same table under the same rules and marked "naša ponuda". "Ne pominje se" (not mentioned) is used where
a firm's site is silent — never "no". No ratings, no logos, no paid placements. Corrections: `/ispravka/`; changes are
logged in `/izmene/`. Legal basis for comparative content: Zakon o oglašavanju, čl. 14.
